# robot-programming

Game readme:

This is a simple snake game with a variable screen size (on initialization).

The game speeds up as you eat food by incrementing the game's FPS. The food spawns in randomly every 20 ticks of the game. The snake grows in size, can travel between screen borders and will end the game if the player runs into himself. There is a working menu and game over screens, as well as a score counter and a high score tracker, which is local per game session.
